# 《思念 · Sinian》双人联机与真机配对指南

本文档提供详细的配对教程，帮助你将两台设备（两台真机 iPhone，或一台 Mac 模拟器 + 一台真机 iPhone）连接并实现跨设备灵动岛互动。

---

## 准备工作

1. **设备网络要求**：
   - 方案 A（同一局域网）：两台设备连接同一个家用/办公室 Wi-Fi。
   - 方案 B（手机热点）：真机 iPhone 开启个人热点，Mac 电脑连接该 iPhone 的热点。

2. **获取服务端 IP 地址**：
   在作为服务器的主机（通常为 Mac 电脑）终端执行：
   ```bash
   ipconfig getifaddr en0
   ```
   例如返回：`172.20.10.12` 或 `192.168.1.100`。

3. **启动信令服务**：
   ```bash
   cd server
   node server.js
   ```
   看到以下提示即表示服务就绪：
   ```
   ❤️  Sinian 信令服务器已就绪!
      HTTP/WS 监听端口: 8080
      健康检查接口: http://localhost:8080/health
   ```

## 配对步骤

### 步骤 1：主设备（设备 A，例如 Mac 模拟器）
1. 启动《思念》App；
2. 点击左上角伴侣昵称头像进入 **【甜蜜配对】**；
3. 配对暗号设置为：`LOVE-520`；
4. 信令服务设置为：`ws://localhost:8080`；
5. 点击 **【连接并配对】**，状态显示为绿色“已连接中转”。

### 步骤 2：副设备（设备 B，例如真机 iPhone 15）
1. 启动《思念》App；
2. 点击左上角伴侣昵称头像进入 **【甜蜜配对】**；
3. 配对暗号设置为：`LOVE-520`（保持与设备 A 完全一致）；
4. 信令服务填入 Mac 的 IP 地址，例如：
   ```text
   ws://172.20.10.12:8080
   ```
   （界面提供“填入 Mac 地址”一键填充按钮）；
5. 点击 **【连接并配对】**；
6. 当两台设备都连接后，顶部状态将变为：
   **🟢 伴侣在线直连 (已就绪)**！

## 常见问题与排查技巧

### Q1：为什么真机收到了想念，但灵动岛没有弹出来？
- **排查 1：iOS 系统权限**
  进入 iPhone **【设置】** -> **【思念】** -> 确保 **【实时活动】** 开关已打开。
- **排查 2：前台回避机制**
  当你的手机停留在《思念》App 界面时，iOS 默认不会在顶部灵动岛显示当前 App。**从底部往上一滑退回手机桌面**或**锁屏**，灵动岛便会立刻浮现。

### Q2：开着共享热点时，灵动岛右侧显示绿色 WiFi 图标？
- **原因**：iOS 遇到多个后台任务（如共享热点 + 想念）时会自动进入“双岛分割模式”。
- **优化**：最新版本已经将对方昵称直接放到了左侧药丸（`❤️ 宝贝`），因此即使开着热点，文字与爱心也清晰完整。

### Q3：如何调整灵动岛停留时长？
- 在 App 主页下方的【灵动岛体验与调试】卡片中，可自由切换：
  - **15 秒自动收起**（默认推荐）：送达后跳动，15 秒后自动消失；
  - **30 秒自动收起**；
  - **常驻陪伴**：一直保留在灵动岛。
- 长按展开灵动岛卡片，右下角提供 **【收起】** 快捷按钮，轻触即可随手关闭。
