## 一、系统构成概览

整个系统由两大部分协同工作：

```
┌────────────────────────────────────────┐
│           Mac / 云端服务器              │
│  [Node.js WebSocket 信令服务 (端口 8080)] │
└───────────────────▲────────────────────┘
                    │
         WebSocket 双向心跳与信令
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
┌──────────────┐        ┌──────────────┐
│  iPhone A    │        │  iPhone B    │
│  (真机客户端) │        │ (或 Mac 模拟器)│
│  + 灵动岛     │        │  + 灵动岛     │
└──────────────┘        └──────────────┘
```

1. **信令中继服务端 (Server)**：位于 `server/server.js`，基于轻量 Node.js WebSocket，负责房间配对、心跳维持、思念信令路由。
2. **客户端应用 (Client App)**：基于 SwiftUI + ActivityKit 开发的 iOS 原生应用，负责触感反馈、心跳发送及灵动岛实时活动管理。

## 二、一键启停脚本 (推荐)

我们在工程的 `scripts/` 目录下提供了一键式 Shell 自动化脚本，免去敲击繁琐系统命令的烦恼。

### 1. 一键启动
进入工程根目录，执行：
```bash
./scripts/start.sh
```

**脚本自动执行的操作：**
- 检查端口 `8080` 占用情况；
- 检查 Node.js 与 `ws` 依赖环境，必要时自动安装依赖；
- 在后台静默启动 `node server.js`，并将运行日志重定向至 `logs/server.log`；
- **智能探测本机 IP**：自动识别个人热点网段（`172.20.10.x`）或 Wi-Fi 局域网网段（`192.168.x.x`），并在终端直接输出真机可直接填写的完整地址（例如 `ws://172.20.10.12:8080`）；
- 提示是否同时自动唤起 Mac 上的 iOS 模拟器。

### 2. 一键停止
进入工程根目录，执行：
```bash
./scripts/stop.sh
```

**脚本自动执行的操作：**
- 读取 `.server.pid` 优雅停止后台 Node.js 信令服务；
- 扫描并释放端口 `8080` 上的任何残留占用；
- 提示是否同时退出 Mac 上的 iOS 模拟器应用（`Simulator.app`）并关闭所有运行中的模拟器设备实例。

## 三、手动启动流程 (分步说明)

如果您希望完全掌控每一步的执行细节，可按以下步骤手动操作：

### 第一步：获取 Mac 局域网或热点 IP
手机连接与 Mac 相同的网络（同 Wi-Fi 或手机开启个人热点供 Mac 连接）。

在 Mac 终端中运行以下命令查看 IP：
```bash
# 如果使用手机个人热点：
ifconfig | grep "inet 172.20.10\." | awk '{print $2}'

# 如果使用普通家庭/办公室 Wi-Fi：
ipconfig getifaddr en0
```
> 假设查得 IP 为 `172.20.10.12`，则手机填写的服务端地址为：`ws://172.20.10.12:8080`。

### 第二步：启动信令服务端
```bash
cd server

# 方式 A：前台运行（终端窗口需保持开启，便于查看实时收发日志）
node server.js

# 方式 B：后台脱机运行（关闭终端窗口也不受影响）
nohup node server.js > ../logs/server.log 2>&1 &
```

可以通过浏览器打开 `http://localhost:8080/health`，若返回类似以下 JSON 则表示服务端正常：
```json
{"status":"ok","clients":0,"rooms":0,"timestamp":1788712000000}
```

### 第三步：启动客户端并进行配对
1. **真机 iPhone**：
   - 在主屏幕点击「思念」App 图标打开；
   - 点击右上角「设置」图标；
   - 在「服务器地址」输入：`ws://<Mac的IP>:8080`（例如 `ws://172.20.10.12:8080`）；
   - 填写与伴侣约定的「房间配对码」（例如 `5201314`）；
   - 点击「保存并连接」，顶部状态指示灯应立即由红变绿（显示「已连接」）。

2. **Mac 模拟器（作为伴侣设备）**：
   ```bash
   # 打开模拟器应用
   open -a Simulator
   
   # 或者直接在 Xcode 中选择 iPhone 16 Pro 运行 Command + R
   ```
   - 在模拟器中的「思念」设置中，服务器地址可直接填写 `ws://127.0.0.1:8080`，房间配对码同样填写 `5201314`。

## 四、手动关闭与清理流程

在完成联调或不再需要运行互动时，请按以下步骤清理后台资源：

### 1. 关闭信令服务端与释放端口
```bash
# 查找并杀死占用 8080 端口的进程
kill -9 $(lsof -t -i :8080) 2>/dev/null || true

# 检查是否还有残留的 node server 进程
pkill -f "node.*server\.js" 2>/dev/null || true
```

### 2. 关闭 iOS 模拟器
```bash
# 优雅退出 Simulator 窗口应用
osascript -e 'tell application "Simulator" to quit'

# 强制关闭所有正在 Booted 的模拟器设备省电/释放内存
xcrun simctl shutdown all
```

### 3. 真机端交互与灵动岛生命周期
- **常驻挂起提醒**：
  - 当伴侣发来想念消息时，灵动岛与锁屏卡片立即挂起，展示伴侣昵称与「想你啦」；
  - **如果不点开，提醒将一直常驻挂在灵动岛上**，不设任何自动超时倒计时；
- **点开查看详情**：
  - 轻触灵动岛或下拉横幅通知，系统将直接打开「思念」App，居中弹出浪漫的思念卡片，展示寄语全文、时间与回复按钮（「我知道啦」/「我也想你」）；
- **退出应用自动消除**：
  - 当你在 App 内看到消息后，上滑返回主屏幕或锁屏，灵动岛上的想念提醒将**自动完全消除**，恢复初始极简黑胶囊状态；
- **彻底关闭 App**：从 iPhone 屏幕底部上滑悬停进入多任务切换界面，向上滑出「思念」卡片彻底退出后台。

## 五、后台常驻守护 (进阶方案)

如果您希望信令服务在 Mac 或云服务器（Linux）上 7×24 小时开机自启、崩溃自动重启，推荐使用 `pm2`：

### 1. 安装 PM2
```bash
npm install -g pm2
```

### 2. 启动并守护服务
```bash
cd server
pm2 start server.js --name "sinian-server"
```

### 3. 常用运维命令
```bash
pm2 status                  # 查看运行状态
pm2 logs sinian-server      # 查看实时输出日志
pm2 restart sinian-server   # 重启服务
pm2 stop sinian-server      # 停止服务
pm2 startup                 # 生成开机自启配置
pm2 save                    # 保存当前进程列表
```

## 六、常见启停问题与排查 (FAQ)

### Q1: 启动时报错 `Error: listen EADDRINUSE: address already in use :::8080`？
- **原因**：端口 `8080` 已被先前的服务或其他应用占用。
- **解决**：
  ```bash
  # 查看是哪个进程占用了 8080 端口
  lsof -i :8080
  # 一键释放
  kill -9 $(lsof -t -i :8080)
  ```

### Q2: 手机打开后顶部状态灯一直显示红色「未连接」？
- **排查步骤**：
  1. **检查 IP 是否正确**：如果手机断开又重连过热点或 Wi-Fi，Mac 的 IP 可能会发生变化。在 Mac 上重新运行 `ipconfig getifaddr en0` 或 `ifconfig` 确认当前实际 IP；
  2. **检查防火墙**：前往 Mac「系统设置」->「网络」->「防火墙」，确认未阻止传入连接；
  3. **测试连通性**：在 iPhone 的 Safari 浏览器中直接输入 `http://<Mac-IP>:8080/health`，看是否能正常显示 JSON。若能打开网页但 WebSocket 连不上，请检查 iOS「设置」->「思念」中是否允许了「本地网络」权限。

### Q3: 模拟器端发送了心动，但手机灵动岛未弹出？
- **排查步骤**：
  1. 确认两台设备的「房间配对码」完全一致（区分大小写）；
  2. 确认手机已经退到主屏幕或锁屏界面（在应用前台时默认在界面内产生跳动动效与触感，退至后台时才会激活灵动岛）；
  3. 确认 iPhone「设置」->「思念」中开启了「实时活动」开关。

### Q4: 个人热点模式下，灵动岛为什么只显示心心没显示文字？
- 我们已在最新版本中将文字内容移至 `compactLeading`，即便开启个人热点导致 iOS 将灵动岛分割为双岛多任务模式（一边显示热点绿色图标），另一侧仍能完整显示「❤️ 宝贝」字样。
